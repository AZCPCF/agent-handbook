## مسئله

بارگذاری همه تعریف‌ها از ابتدا ساده ولی **گران** است. با ده‌ها ابزار، تعریف‌ها می‌توانند قبل از شروع کار بخش بزرگی از پنجره را بگیرند.

## راهبردهای Discovery

| راهبرد | چطور کار می‌کند | مبادله |
|---|---|---|
| **همه از ابتدا** | همه ابزارها در هر نوبت دیده می‌شوند | ساده، گران، در مقیاس گیج‌کننده |
| **مجموعه‌های محدود** | ابزار متفاوت برای هر Agent یا تسک | نیاز به برنامه‌ریزی، بسیار مؤثر |
| **جست‌وجو / بارگذاری تعویقی** | Agent در یک فهرست جست‌وجو می‌کند و فقط لازم را بارگذاری می‌کند | Context کمتر، یک گام جست‌وجوی اضافه |
| **Progressive Disclosure** | اول نام‌ها، جزئیات در صورت نیاز | همان ایده Skills (روز ۲) |

## رویه خوب

1. **بر اساس نقش محدود کن:** Subagent بازبین فقط ابزار خواندن می‌گیرد.
2. **سرورهای بلااستفاده** را برای هر پروژه یا Session غیرفعال کن.
3. **برای جست‌وجو نام و توضیح بنویس:** کلماتی که کسی واقعاً می‌گوید را بگنجان.
4. **بر اساس دامنه گروه‌بندی کن** تا ابزارهای مرتبط با هم پیدا شوند.

## هزینه را بسنج

Context پایه را قبل و بعد از اتصال یک سرور ببین (`/context` در Claude Code). اگر سروری هزینه بالایی دارد و کم استفاده می‌شود، محدودش کن.

## خودآزمایی

کدام ابزارها را هر Agent باید ببیند و کدام را فقط یک Subagent مشخص؟
