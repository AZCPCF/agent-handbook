## چرا Headless؟

چت تعاملی برای کاوش است. **Headless** Agent را مثل یک دستور اجرا می‌کند: یک Prompt ورودی، یک نتیجه خروجی. این Agent را اسکریپت‌پذیر، زمان‌بندی‌پذیر و تست‌پذیر می‌کند.

## کاربردهای رایج

| کاربرد | مثال |
|---|---|
| بازبینی PR در CI | بازبینی Diff و ثبت یافته‌ها |
| تسک‌های دسته‌ای | به‌روزرسانی مستندات در فایل‌های زیاد |
| بررسی زمان‌بندی‌شده | گزارش شبانه Dependency یا TODO |
| ارزیابی | اجرای مجموعه تسک ثابت برای مقایسه Setupها (روز ۶) |

## شکل یک فراخوانی Headless

```bash
# one-shot prompt, machine-readable output
claude -p "Review the staged diff against our rules and list problems" \
  --output-format json \
  --max-turns 8 \
  --allowedTools "Read,Grep,Glob"
```

:::note
نام Flagها بین نسخه‌ها ممکن است عوض شود. با `claude --help` و مستندات CLI تأییدشان کن.
:::

## ایمنی در حالت Headless

1. ابزارها را **صریحاً Allow-list** کن؛ انسانی نیست که تأیید کند.
2. **دور و بودجه را محدود کن** تا فرار نکند.
3. **پیش‌فرض فقط‌خواندنی**؛ نوشتن را باریک بده.
4. **Sandbox و بدون اعتبارنامه Production** در CI.
5. خروجی را پیش از استفاده در اسکریپت **غیرقابل‌اعتماد** فرض کن.

## پارس کردن نتیجه

خروجی ساختاریافته بخواه و فیلد وضعیت و متن نتیجه را بررسی کن؛ به‌جای فرض موفقیت، Job را روی خطا Fail کن.

## خودآزمایی

یک مرحله CI طراحی کن که روی هر PR بازبینی فقط‌خواندنی اجرا کند. کدام ابزارها را مجاز می‌کنی؟
