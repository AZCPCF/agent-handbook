## کدام مکانیزم Extension؟

| نیاز | مکانیزم | قطعی؟ |
|---|---|---|
| صدا زدن سیستم بیرونی با آرگومان | MCP Tool | خود ابزار بله، انتخاب با مدل |
| خواندن داده مرجع در لحظه نیاز | MCP Resource | بله |
| قالب تکرارشونده فعال‌شده توسط کاربر | MCP Prompt / Command | بله |
| دنبال کردن رویه با قضاوت | Skill | خیر |
| همیشه بعد از Y کار X را بکن | Hook | بله |
| کارگر تخصصی با Context جدا | Subagent | خیر |
| اشتراک همه موارد بالا | Plugin | — |
| اجرا در CI یا اسکریپت | Headless | بسته به Prompt |

## قاعده Prompt در برابر Hook

| | Prompt | Hook |
|---|---|---|
| تضمین | ندارد | قوی |
| انعطاف | زیاد | کم |
| مناسب برای | ترجیحات | Invariantها |

## Primitiveهای MCP

| Primitive | کنترل با | کاربرد |
|---|---|---|
| Tool | مدل | اقدام‌ها |
| Resource | اپلیکیشن | داده مرجع |
| Prompt | کاربر | قالب‌ها |

## راهبردهای Discovery

| راهبرد | هزینه Context | پیچیدگی |
|---|---|---|
| همه از ابتدا | زیاد | کم |
| محدود برای هر Agent | کم | متوسط |
| جست‌وجو / تعویقی | کمترین | بیشتر |
