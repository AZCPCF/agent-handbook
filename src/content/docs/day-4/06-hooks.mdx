## چرا Hook؟

Prompt می‌گوید «لطفاً تست‌ها را اجرا کن». **Hook تست‌ها را هر بار اجرا می‌کند.** Hookها رفتار حیاتی را از اختیار مدل بیرون می‌آورند و به کد قطعی می‌سپارند.

| | دستور در Prompt | Hook |
|---|---|---|
| قابلیت اعتماد | معمولاً رعایت می‌شود | همیشه اجرا می‌شود |
| می‌تواند اقدام را مسدود کند | خیر | بله |
| هزینه | توکن در هر نوبت | هیچ، مگر خروجی بدهد |
| مناسب برای | راهنمایی | نرده ایمنی و اتوماسیون |

## کاربردهای رایج

| کاربرد | مثال |
|---|---|
| **Quality Gate** | اجرای Typecheck و Lint بعد از هر ویرایش TypeScript |
| **حفاظت** | مسدود کردن ویرایش Migrationهای موجود یا `.env` |
| **فرمت‌دهی** | اجرای Formatter بعد از نوشتن فایل |
| **ممیزی** | لاگ هر دستور Shell |
| **تزریق Context** | افزودن اطلاعات Branch یا تیکت در آغاز Session |
| **اعلان** | وقتی Agent ورودی لازم دارد به تو خبر بده |

## Hook چطور با Agent حرف می‌زند

- **داده رویداد** (نام ابزار، آرگومان‌ها) را به‌عنوان ورودی می‌گیرد.
- یک **Exit Status** برمی‌گرداند؛ یک مقدار ویژه می‌تواند **مسدود** کند و پیامش را به‌عنوان بازخورد به Agent بفرستد.
- خروجی Hook برای Agent قابل‌دیدن می‌شود، پس **کوتاهش کن**.

:::caution
Hookها **با مجوزهای تو** اجرا می‌شوند. یک Hook بی‌دقت یک حفره امنیتی است. مثل اسکریپت Production بازبینی‌شان کن.
:::
