## قطعی در برابر Agentic: هر گام مال کیست؟

| گام... | مالک |
|---|---|
| ثابت، تکرارشونده، حیاتی از نظر ایمنی | کد (Workflow) |
| نیازمند قضاوت روی کد ناشناخته | Agent |
| غیرقابل‌بازگشت | کد + تأیید انسانی |
| اعتبارسنجی | اول کد (تست، CI)، بعد Agent |

| شکست | اولین دفاع |
