## تک‌Agent در برابر چند-Agent

| | تک‌Agent | چند-Agent |
|---|---|---|
| پیچیدگی | کم | زیاد |
| هزینه | کمتر | بیشتر |
| موازی‌سازی | ندارد | دارد |
| بازبینی مستقل | ضعیف | قوی |
| کی استفاده شود | بیشتر تسک‌ها | کار موازی، پرنویز یا پرریسک |

## الگوها در یک نگاه

| الگو | مناسب برای | ریسک |
|---|---|---|
| ReAct | دیباگ، کاوش | پرسه زدن |
| Plan-and-Execute | Feature، Refactor | برنامه کهنه |
| Orchestrator-Workers | Featureهای چندبخشی | فشار روی Lead |
| Pipeline | نقش‌های تکرارشونده | انعطاف‌ناپذیر |
| Generate-and-Critique | کنترل کیفیت | حلقه بی‌پایان |

## مکانیزم‌های ایزوله‌سازی

| مکانیزم | چه چیزی را ایزوله می‌کند | چه چیزی را نه |
|---|---|---|
| Subagent | Context | فایل‌ها، DB |
| Worktree | فایل‌ها و Branch | DB، Port، سرویس‌ها |
| Permissions | قابلیت‌ها | خطاهای استدلال |
| Sandbox | محیط اجرا | خطاهای منطقی |

## موازی یا ترتیبی؟

| وضعیت | انتخاب |
|---|---|
| خواندن و تحقیق | موازی |
| نوشتن، ماژول‌های جدا، Interface توافق‌شده | موازی |
| وابسته به خروجی دیگری | ترتیبی |
| همان فایل یا جدول | ترتیبی |

## نقش‌ها

| نقش | ویرایش می‌کند؟ | خروجی کلیدی |
|---|---|---|
| Planner | خیر | برنامه و معیارها |
| Coder | بله (Worktree خودش) | Commitها |
| Reviewer | خیر | حکم و یافته‌ها |
