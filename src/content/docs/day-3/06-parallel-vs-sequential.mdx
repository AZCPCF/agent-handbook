## آزمون تصمیم

دو تسک فقط وقتی موازی‌اند که **هیچ‌کدام به خروجی دیگری نیاز نداشته باشد** و **روی فایل یا State مشترک ویرایش نکنند**.

| شرط | اجرا |
|---|---|
| خواندن و تحقیق مستقل | موازی (امن، ادغام ارزان) |
| نوشتن مستقل در ماژول‌های مختلف | موازی با Branch جدا |
| B به نتیجه یا Interface مربوط به A نیاز دارد | ترتیبی |
| همان فایل، همان جدول، همان Config | ترتیبی |

## گراف وابستگی (کاربران و نقش‌ها در CRM)

```text
[1 schema + migration]
        |
   +----+-------------+
   v                  v
[2 permission lib] [3 API endpoints]   <- parallel after the interface is fixed
        |                  |
        +--------+---------+
                 v
            [4 UI]
                 v
            [5 e2e tests]
```

## هزینه‌های موازی‌سازی

- **هزینه ادغام:** تعارض و باگ‌های Integration.
- **بار بازبینی:** Diff بیشتری برای خواندن تو.
- **انحراف Spec:** Agentها ممکن است Interface را متفاوت تفسیر کنند.

:::tip
**خواندن و تحقیق** را آزادانه موازی کن. **نوشتن** را فقط بعد از توافق روی Interfaceها در یک Spec موازی کن.
:::
