## الگوها

- **ReAct** (Reason + Act): کمی فکر کن، اقدام کن، مشاهده کن، تکرار. برنامه‌ریزی و اجرا **در هم تنیده‌اند**.
- **Plan-and-Execute:** اول یک **برنامه کامل** بساز، بعد گام‌به‌گام اجرا کن و اگر واقعیت فرق کرد دوباره برنامه بریز.

```text
ReAct:             think -> act -> observe -> think -> act -> observe ...
Plan-and-Execute:  plan[1..n] -> execute 1 -> execute 2 -> ... (re-plan on failure)
```

## مقایسه

| | ReAct | Plan-and-Execute |
|---|---|---|
| سازگاری با غافلگیری | عالی | نیاز به Re-plan صریح |
| پیش‌بینی‌پذیری | کمتر | بیشتر (برنامه را می‌شود بازبینی کرد) |
| هزینه | ممکن است پرسه بزند | برنامه هزینه اولیه دارد، گام‌ها متمرکز می‌مانند |
| نظارت انسانی | سخت (حرکت‌های ریز زیاد) | آسان (برنامه را تأیید می‌کنی) |
| مناسب برای | دیباگ، کاوش | Feature، Refactor، هر چیز پرریسک |

## ترکیب در عمل

1. تسک را **Plan** کن (کاوش فقط‌خواندنی، بدون ویرایش).
2. **تو برنامه را بازبینی و تأیید می‌کنی.**
3. با **ReAct** داخل هر گام اجرا کن (اجرا، مشاهده، رفع).
4. اگر گامی برنامه را باطل کرد، **Re-plan** کن.

:::note
Plan Mode در Claude Code گام ۱ و ۲ را پشتیبانی می‌کند: Agent پیش از تغییر هر چیز کاوش می‌کند و پیشنهاد می‌دهد.
:::

## قاعده سرانگشتی

هرچه تغییر غیرقابل‌بازگشت‌تر یا گسترده‌تر باشد، پیش از هر ویرایش **برنامه بازبینی‌شده** بیشتر لازم است.
