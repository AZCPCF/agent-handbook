## ایده

به‌جای بارگذاری همه چیز، **شناسه‌های سبک** (مسیر فایل، لینک، کوئری، عنوان) را نگه دار و بگذار Agent داده را **در لحظه نیاز** بارگذاری کند؛ مثل توسعه‌دهنده‌ای که می‌داند چیزها کجاست ولی کل ریپو را حفظ نکرده.

## Progressive Disclosure

```text
Level 0: index        "docs/domain/invoices.md - invoice rules"

```

## مبادله‌ها

| | از قبل بارگذاری | Just-in-Time |
|---|---|---|
| سرعت هر گام | سریع‌تر | کندتر (فراخوانی‌های اضافه) |
| مصرف پنجره | سنگین | سبک |
| ریسک | نویز | Agent ممکن است نگاه نکند |
| نیاز دارد | ساختار کم | نام‌گذاری خوب و فهرست |

## چطور کار کند؟

1. برای هر سند یک جمله هدف بنویس.
2. یک فایل نقشه داشته باش که به بقیه اشاره می‌کند.
3. نام‌گذاری یکدست داشته باش تا جست‌وجو موفق شود.
4. در دستورالعمل‌ها بگو برای هر نوع تسک **اول کجا را ببیند**.

برای پنج سند CRM خودت یک جمله هدف بنویس.
