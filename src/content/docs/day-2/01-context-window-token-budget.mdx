## Context چیست؟

مدل در هر فراخوانی **فقط** چیزی را می‌بیند که داخل Context Window است: System Prompt، تعریف ابزارها، دستورالعمل‌های پروژه، تاریخچه گفتگو و نتایج ابزارها. چیز دیگری برایش وجود ندارد. واحد این پنجره Token است.

## بودجه‌ات را چه کسی خرج می‌کند؟

| مصرف‌کننده | توضیح |
|---|---|
| System Prompt و تعریف ابزارها | هزینه ثابت در هر نوبت |
| دستورالعمل پروژه (`CLAUDE.md`) | هر Session بارگذاری می‌شود |
| تاریخچه گفتگو | هر نوبت بزرگ‌تر می‌شود |
| نتایج ابزارها | اغلب بزرگ‌ترین مصرف‌کننده (لاگ، فایل‌های حجیم) |
| خروجی و استدلال مدل | آن هم حساب می‌شود |

## فکر کردن با بودجه

- پنجره **محدود** است و کیفیت قبل از پر شدن کامل افت می‌کند (به *Context Rot* نگاه کن).
- با توکن مثل حافظه در سیستم‌های Embedded رفتار کن: **عمدی تخصیص بده**.
- برای هر مورد بپرس: *آیا این تصمیم بعدی را تغییر می‌دهد؟* اگر نه، جایش اینجا نیست.

```text
total window
 = fixed (system + tools + instructions)
 + history
 + tool results
 + room to think and answer   <- never spend this
```

:::tip
در Claude Code، دستور `/context` نشان می‌دهد الان چه چیزی پنجره‌ات را مصرف می‌کند. قبل از تسک‌های طولانی اجرایش کن.
:::

## خودآزمایی

1. سه مصرف‌کننده بزرگ توکن در آخرین Session خودت را فهرست کن.
2. اول از کدام بخش هزینه ثابت کم می‌کنی؟
