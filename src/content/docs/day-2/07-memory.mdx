## لایه‌های حافظه

| لایه | طول عمر | مثال |
|---|---|---|
| Working Memory | یک نوبت | نتایج فعلی ابزار |
| Session Memory | یک Session | تاریخچه گفتگو |
| Persistent Memory | بین Sessionها | فایل‌های داخل ریپو، یادداشت‌های حافظه |

## چه چیزی در حافظه ماندگار می‌ماند

- قراردادها و دستورها (چطور تست اجرا شود)
- **تصمیم‌های** معماری و دلیل‌هایشان
- قواعد دامنه
- دام‌های شناخته‌شده

## چه چیزی نه

- Secret، توکن، داده واقعی مشتری
- وضعیت موقت تسک که منقضی می‌شود
- چیزهایی که کد خودش روشن می‌گوید
- حدس‌های Agent که به‌عنوان واقعیت ثبت شده‌اند

## بهداشت حافظه

1. **منبع واحد حقیقت.** واقعیت‌ها را بین فایل‌ها تکرار نکن.
2. تصمیم‌ها را **تاریخ‌دار و صاحب‌دار** کن.
3. مرتب **مرور و هرس** کن؛ حافظه کهنه، آلودگی است.
4. تغییر فایل‌های حافظه مشترک با **بازبینی انسانی**.

## حافظه کجا زندگی می‌کند؟

برای دانش حیاتی تیم، **فایل‌های داخل ریپو** را ترجیح بده (نسخه‌دار و قابل بازبینی). قابلیت‌های حافظه خود ابزار راحت‌اند ولی بررسی کن چه چیزی ذخیره کرده‌اند.
