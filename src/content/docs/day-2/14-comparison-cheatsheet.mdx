## دانش کجا باید زندگی کند؟

| دانش | جا | بارگذاری |
|---|---|---|
| درست برای هر تسک | Project Instructions | همیشه |
| درست برای یک بخش | Path-scoped Rule | وقتی آن فایل‌ها درگیرند |
| Workflow تکرارشونده | Skill | وقتی فعال شود |
| جزئیات دامنه، ADR | `docs/` | در لحظه نیاز |
| پیشرفت تسک فعلی | فایل پیشرفت | آغاز Session |
| Secret، داده واقعی | هیچ‌جای Context | هرگز |

## مشکلات Context

| مشکل | علامت | راه‌حل |
|---|---|---|
| خیلی زیاد | کند، گران، بی‌تمرکز | کوتاه کردن، JIT |
| کهنه | قواعد قدیمی را دنبال می‌کند | هرس، منبع واحد |
| گم‌شده | تصمیم‌ها را فراموش می‌کند | یادداشت بیرون پنجره |
| آلوده | بن‌بست‌ها را تکرار می‌کند | Session تازه / Compact |

## Memory در برابر Context در برابر State

| | Context | Memory | State |
|---|---|---|---|
| طول عمر | پنجره | بین Sessionها | بین Sessionها |
| نگه می‌دارد | آنچه مدل الان می‌بیند | قراردادها، تصمیم‌ها | پیشرفت تسک |
| ویرایش توسط | Harness | با بازبینی انسانی | Agent |

## راهبردها

| راهبرد | هزینه الان | هزینه بعدی |
|---|---|---|
| بارگذاری از قبل | زیاد | کم |
| Just-in-Time | کم | متوسط |
| Compaction | متوسط | ریسک از دست رفتن |
| Session تازه + Handoff | کم | نیاز به یادداشت خوب |
