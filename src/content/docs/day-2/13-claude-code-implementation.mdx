:::note
نام و رفتار قابلیت‌ها در طول زمان عوض می‌شود. این صفحه را یک نقشه بدان و جزئیات را در مستندات رسمی Claude Code تأیید کن.
:::

| مفهوم | قابلیت Claude Code |
|---|---|
| Project Instructions | `CLAUDE.md` (سطح پروژه و کاربر) |
| دستورالعمل بین‌ابزاری | `AGENTS.md`؛ روش رایج ارجاع به آن از داخل `CLAUDE.md` است |
| یادداشت‌های ماندگار | قابلیت‌های Memory و فایل‌هایی که در ریپو نگه می‌داری |
| قواعد Path-scoped | فایل‌های قاعده در `.claude/rules/` |
| Progressive Disclosure | Skills در `.claude/skills/` |
| بررسی پنجره | `/context` |
| Compaction | `/compact` (با دستور تمرکز اختیاری) |
| ایزوله‌سازی | Subagents (روز ۳) |

## تمرین

1. `/context` را روی یک Session تازه اجرا کن و عدد پایه را یادداشت کن.
2. بعد از خواندن یک فایل بزرگ دوباره اجرا کن.
3. `/compact` را با یک جمله تمرکز اجرا کن و ببین چه چیزی باقی ماند.
4. یک بخش کم‌استفاده از `CLAUDE.md` را به یک Skill ببر و تغییر عدد پایه را ببین.

## خودآزمایی

هزینه ثابت Session تو، قبل از اینکه چیزی تایپ کنی، چقدر است؟
