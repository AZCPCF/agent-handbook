## Where things live

| Capability | Typical location |
|---|---|
| Hooks | `settings.json` (`.claude/settings.json` for the project) |
| MCP servers | Project MCP config file or the CLI's `mcp` commands |
| Skills | `.claude/skills/<name>/SKILL.md` |
| Subagents | `.claude/agents/<name>.md` |
| Plugins | Installed from a marketplace or local path |
| Headless | `claude -p ...` |

## Hook configuration pattern

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit",
        "hooks": [
          { "type": "command", "command": ".claude/hooks/ts-check.sh" }
        ]
      }
    ],
    "PreToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit",
        "hooks": [
          { "type": "command", "command": ".claude/hooks/protect-paths.sh" }
        ]
      }
    ]
  }
}
```

## MCP configuration pattern

```json
{
  "mcpServers": {
    "crm-docs": { "type": "http", "url": "https://example.com/mcp" }
  }
}
```
