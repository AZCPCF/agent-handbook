## Two strategies

| Strategy | How | Good for | Risk |
|---|---|---|---|
| **Upfront loading** | Put material in before the task starts | Small, always-needed rules | Bloat |
| **Retrieval at runtime** | Agent searches and reads when needed | Large codebases, docs | Misses, extra steps |
| **Hybrid** | Small core upfront, rest retrieved | Most real projects | Needs good structure |

## Retrieval tools for coding agents

| Tool | Finds |
|---|---|
| Glob / file listing | Files by name or path |
| Grep / text search | Exact symbols and strings |
| Semantic search | Concepts, when names are unknown |
| Reading with line ranges | Only the relevant slice |

## Rules of thumb

- Preload only what is needed in **almost every** task.
- Make the rest **findable**: clear names, an index, a docs map.
- Prefer retrieving a **slice** over a whole file.
- Good structure is retrieval infrastructure.
