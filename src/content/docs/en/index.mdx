title: Agent Engineering Handbook
description: A 7-day, book-style bootcamp on managing coding agents for a real CRM/ERP project.
---

This handbook turns the 7-day **Agent Engineering Bootcamp** into a readable book. The goal is not to memorise one tool, but to learn how to **manage a coding agent like a software engineer on your team**: give it the right access, split its work, verify its output, and keep control of a three-month project.
